# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

This project focuses on analyzing customer shopping behavior using **Python, SQL, and Power BI** to extract meaningful business insights from customer purchase data.

The project includes:

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* SQL Database Integration
* Interactive Power BI Dashboard
* Business Insight Generation

---

# 🚀 Technologies Used

| Technology       | Purpose                   |
| ---------------- | ------------------------- |
| Python           | Data Cleaning & Analysis  |
| Pandas           | Data Manipulation         |
| NumPy            | Numerical Operations      |
| Jupyter Notebook | Development Environment   |
| MySQL            | Database Management       |
| SQLAlchemy       | Database Connectivity     |
| Power BI         | Dashboard & Visualization |

# 📊 Key Features

## ✅ Data Cleaning

* Handled missing values
* Renamed columns
* Removed duplicate/unnecessary data
* Filled missing review ratings using median values

## ✅ Feature Engineering

* Created customer age groups
* Converted purchase frequency into numerical values
* Structured data for better analysis

## ✅ SQL Integration

* Connected Python with MySQL database
* Stored cleaned data into SQL tables
* Executed analytical SQL queries

## ✅ Interactive Dashboard

The Power BI dashboard provides:

* Customer Purchase Trends
* Product Category Analysis
* Review Rating Analysis
* Shopping Frequency Insights
* Customer Demographics Visualization
